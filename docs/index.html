From code to considered review.

The MCP gives your AI the OES catalog and a structured way to show evidence. The developer stays in control of the interpretation.

Add the OES MCP to a compatible coding assistant. It runs locally alongside your project.

Use it with your AI.

Connect the local MCP server from this repository. Node.js 20 or newer is required.

# Clone and build the local MCP server
git clone https://github.com/ike5/open-ethics-standard.git
cd open-ethics-standard
npm install --prefix packages/oes-mcp
npm run build:mcp
# Example MCP client configuration
{
  "mcpServers": {
    "open-ethics-standard": {
      "command": "node",
      "args": ["/path/to/open-ethics-standard/packages/oes-mcp/dist/server.js"]
    }
  }
}

Client setup varies. Follow the repository README for current instructions. Interactive review views require MCP Apps support; other clients receive a readable report.

Open standard. Open process.

The catalog is a shared vocabulary, not a law, certification, or automated ethics score. Anyone can propose additions, amendments, and corrections through a pull request.

One source of truth

The Markdown standard is transformed into the structured catalog used by the MCP during the build.

Evidence with citations

Possible matches point to project locations and the OES section that prompted review.

Human judgment

AI can miss context. Developers assess each finding and decide what to do next.
