Your AI reviews

Read the setup guide ↗

Works with Codex, Claude Code, Cursor, VS Code, and other local MCP clients.

Reports are saved on your machine and work offline. OES never sees your code; your AI provider’s own policies still apply.

Prefer to set it up manually?

Requires Node.js 20+.

git clone https://github.com/ike5/open-ethics-standard.git "$HOME/.local/share/open-ethics-standard"
cd "$HOME/.local/share/open-ethics-standard"
npm ci --prefix packages/oes-mcp
npm run setup:mcp

Add the printed config to your AI client. The setup guide has client commands, rechecks, and troubleshooting.
